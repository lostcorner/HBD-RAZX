## 当前限制

- 回忆和纠错目前只保存在访问者浏览器的 `localStorage` 中。
- 当前页面播放器使用 Apple 30 秒预览；其他平台主要提供搜索或歌单入口，不是统一的嵌入式播放器。
- GitHub Pages 只负责静态前端托管，评论、投票和点赞需要后端与数据库。
- Apple 预览是否存在取决于地区目录和歌曲匹配结果；没有预览的记录不会进入寻迹播放池，但仍保留在档案中。
- 网易云歌单的“当前曲目”是抓取当天的快照，会因版权下架而与历史实际播放不一致；历史简介和贴吧原帖优先。
- 原始贴吧资料 `resource/` 仅保留在本地，不纳入 Git 跟踪。
